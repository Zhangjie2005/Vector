# 事件相机三维重建论文知识图谱构建与应用项目报告


## 项目概述

本项目围绕事件相机三维重建，收集并整理 20 篇论文，建立可追溯到论文原文位置的知识图谱，在 Neo4j Aura 中导入 703 个节点和 774 条关系。应用部分只选两类：依据图谱实体进行研究路线分类，以及从图谱事实生成带论文来源的问答。分类在 20 折留一论文验证中正确 14 篇；生成任务形成 20 个答案和 131 条可回溯的事实。

## 1 收集论文

研究方向覆盖几何、NeRF 和 3DGS 三条技术路线，分别纳入 5、9、6 篇。论文年份为 2016—2025 年。筛选时优先保留与事件相机三维结构、深度估计、场景表示或新视角合成直接相关、能找到论文原文入口且能定位方法或实验事实的研究。逐篇题名、年份、来源和筛选依据见[论文清单](论文清单_20篇.md)。原始候选中的 S07、S08 没有纳入最终 20 篇图谱，后续数量和应用评价均按这 20 篇统计。

## 2 构建知识图谱

### 2.1 抽取与整理

我为每篇论文记录“主语、原始关系、宾语、依据位置”，得到 20 份[逐篇抽取表](reextract/)。例如 S04 中有“EF-3DGS—输入—连续事件流（摘要）”和“EF-3DGS—场景表示—3D Gaussian Splatting（标题）”。[构建脚本](reextract/build_aura_import.ps1)读取这些表和论文元信息，清理名称空格，合并部分同义实体，将“连续事件流”等归一为“事件相机事件流”，并按名称去重、分配节点 ID。节点类别由规则判断；原始中文谓词映射为规范关系值，映射不上的关系保留为 `RELATED_TO`，同时保留其 `raw_predicate`。

### 2.2 节点、关系与来源

最终 CSV 包含 **703 个节点、774 条关系、45 种规范关系值**。节点属性为 `id`、`name`、`category`、`doc_ids`。其中 `doc_ids` 用 `|` 记录实体涉及的论文编号。

| 节点类别 | 含义 | 数量 |
|---|---|---:|
| Author | 作者 | 78 |
| ChallengeOrScenario | 挑战或场景 | 42 |
| Concept | 概念 | 333 |
| Dataset | 数据集 | 11 |
| Method | 方法 | 92 |
| MetricOrLoss | 指标或损失 | 32 |
| Paper | 论文 | 20 |
| Sensor | 传感器 | 13 |
| TaskOrOutput | 任务或输出 | 82 |

关系表保存起点 `source`、终点 `target`、规范谓词 `type`、原始谓词 `raw_predicate`、所属论文 `paper_id`、论文标题、年份、会场、路线，以及 `source_url`、`evidence_location`、`evidence`。`evidence` 是三元组的结构化转述，不是原文逐字引文。下表列出最常见的规范谓词。

| 规范谓词 | 关系数 |
|---|---:|
| `RELATED_TO` | 260 |
| `AUTHORED_BY` | 94 |
| `MEASURED_BY` | 66 |
| `USES_METHOD` | 54 |
| `COMPARED_WITH` | 49 |
| `PRODUCES_OUTPUT` | 36 |
| `HAS_COMPONENT` | 34 |
| `USES_INPUT` | 31 |
| `PROPOSES` | 20 |
| `ADDRESSES_TASK` | 14 |
| `USES_SENSOR` | 11 |
| `USES_REPRESENTATION` | 8 |

Neo4j 中的边统一使用实际关系类型 `:RELATED_TO`；上表的规范谓词保存在边属性 `r.type`。其中 **260 条**关系的规范谓词仍较宽泛，具体表达可查看 `r.raw_predicate`。

### 2.3 结构与来源核验

[审计脚本](aura_import_reextracted/audit_aura.py)将导出 CSV 与 20 份抽取表逐项对照：703 个节点 ID 唯一；774 条关系的两端均能找到节点；按“起点、终点、原始谓词、论文”判断没有重复；每条边的原始谓词、证据位置、原文 URL 与逐篇表一致。Aura 补导脚本运行后报告数据库中存在 703 节点、774 关系、20 篇论文和 45 种规范谓词。该核验确认结构与记录可追溯，不能代替对 774 条学术陈述逐句阅读原文。

## 3 图谱可视化展示

可双击[本地图谱展示](图谱可视化_20篇.html)，在“20 篇概览”与“逐篇局部图”之间切换。概览展示论文及其提出的方法，局部图可查看 S04 的方法、输入、任务、技术与评估关系。点击节点或连线可查看属性、原始谓词、原文链接和证据位置。[最新展示 PPT](事件相机三维重建-基于20篇论文的知识图谱构建与应用.pptx)已按原文件复制，包含图谱与两项应用展示；PPT 第 5 页局部案例的图片内容与 S04 标题不一致，报告以 CSV 和本地图谱的 S04 关系为准。

在 Neo4j Aura 中，节点先以 `:Entity` 导入，后按 `category` 增加 `:Paper`、`:Method` 等标签。展示 S04 的实际关系可运行：

```cypher
MATCH (a:Entity)-[r:RELATED_TO]->(b:Entity)
WHERE r.paper_id = 'S04'
RETURN a, r, b LIMIT 80;
```

局部案例中，S04 论文提出 EF-3DGS；EF-3DGS 使用视频帧和事件相机事件流，面向自由轨迹场景重建与新视角合成，并采用 3D Gaussian Splatting 表示。相应边可通过 `paper_id`、`source_url` 和 `evidence_location` 追溯。浏览器本地图是用导入 CSV 绘制的互动图，和 Aura 中的数据同源，不能充当 Aura 网页截图。

## 4 应用一：研究路线分类

**输入与输出。** 输入为一篇论文编号及其在图谱中连接的可见实体；输出为“几何、NeRF、3DGS”之一，并保留逐篇预测和解释特征。

**如何使用图谱。** 程序将论文连接的实体节点 ID 作为二值特征，仅利用该实体是否出现。为避免直接读取答案，排除论文和作者节点、指标或损失节点、该论文提出的方法、数字开头的实体，以及名称含 NeRF、Gaussian、3DGS、高斯、辐射场的实体。每折留出一篇，仅用其他 19 篇计算类别先验和共享实体在各类别的频次；拉普拉斯平滑系数为 1。代码见[分类与生成程序](aura_import_reextracted/applications_20.py)。

**评价结果。** 20 折留一论文验证正确 **14/20，准确率 70%**；每折只猜训练集中最多类别的基线正确 **9/20，准确率 45%**。混淆矩阵如下，行是真实类别，列是预测类别。

| 真实类别 | 几何 | NeRF | 3DGS |
|---|---:|---:|---:|
| 几何 | 3 | 0 | 2 |
| NeRF | 1 | 5 | 3 |
| 3DGS | 0 | 0 | 6 |

**案例与不足。** G05（DERD-Net）预测为几何，真实也是几何。它与 G01 共享“视差空间图 DSI”，与 G04 共享“三维卷积”，与 G01/G02 共享“平均深度误差”等图谱实体。G03、G04、N02、N05、N06、N09 被误分；样本仅 20 篇，实体命名和抽取范围会影响结果，70% 不能代表新论文的外部泛化能力。部分用于解释的“平均深度误差”等实体在节点表中被规则划到 `TaskOrOutput`，说明类别规则仍有改进空间。

## 5 应用二：基于图谱的有来源问答生成

**输入与输出。** 输入为论文编号及关于方法、输入、任务、技术或评估数据的问题；输出为图谱事实组织的中文回答，每个事实附论文链接和原文位置。可在[离线交互页面](aura_import_reextracted/第4项_浏览器交互展示.html)选择论文并输入问题。

**如何使用图谱。** 程序从该论文的 `PROPOSES`、`USES_INPUT`、`ADDRESSES_TASK`、`PRODUCES_OUTPUT`、`USES_REPRESENTATION`、`HAS_COMPONENT`、`EVALUATED_ON` 等边中筛选事实，使用固定模板组织文字。没有对应边时不补写。离线页面按提问词筛选已有事实；这一应用不调用大模型。

**评价结果。** 共生成 **20 个答案、131 条事实**。逐字段核对显示 131/131 条事实可以匹配图谱边，并带来源链接和位置；方法、输入、任务或输出字段覆盖 20/20 篇，明确的 `EVALUATED_ON` 数据集边只覆盖 5/20 篇。结构可回溯率是 100%，只说明答案有图谱依据，不证明原文学术事实都已逐句人工复核。

**案例与不足。** 对 S04，生成结果包含 EF-3DGS、视频帧、事件相机事件流、自由轨迹场景重建、新视角合成、3D Gaussian Splatting、事件生成模型 EGM，并给出摘要、标题、第 4 节等依据位置。模板可组织已有事实，但不能推导新结论；缺少数据集边的论文不会得到评估数据句子。若抽取事实有误，回答也会继承错误。自由提问只在本地图谱事实范围内有效。

## 6 复现与交付

本文件夹包含论文清单、20 份逐篇抽取表、导入 CSV、审计记录、可视化 HTML、最新 PPT、分类与生成代码、机器可读结果和逐篇答案。运行方式见[运行说明](README_运行与提交.md)。公开上传副本已去除姓名和学号；本地原始文件保留原有内容。
